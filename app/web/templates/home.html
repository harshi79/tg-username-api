Status model

Every check produces exactly one verdict. The API only reports available when Telegram clearly does not resolve the handle and Fragment has no listing. Anything ambiguous becomes unknown.

StatusMeaning
taken Resolves on Telegram (channel, group, bot) or Fragment "claimed" report consistent with Telegram.
fragment_collectible Not publicly resolvable on Telegram, but tracked by Fragment as a collectible. Not freely claimable.
available Clean negative on Telegram and no Fragment listing, with no upstream errors.
invalid Input failed local validation. No external request was made.
unknown Could not safely determine state. Never assume availability from this status.
